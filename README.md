# Replay

Replay is a durable and replayable execution engine for AI agents.

The project focuses on building reliable AI applications through concepts
from backend engineering and distributed systems.

## Project Goals

- Durable execution state and append-only event history
- Reliable tool execution and idempotency
- Worker coordination using leases and fencing tokens
- Replayable execution with deterministic playback
- Fault-tolerant execution and recovery
- Observability and testing of distributed behavior

## Technology Stack

- Python 3.12 and asyncio
- FastAPI
- PostgreSQL
- Redis Streams
- Docker Compose
- OpenTelemetry, Prometheus and Grafana
- pytest and Hypothesis

## Project Status

This project is under active development.

The implementation follows a milestone-based development plan.
Features will be documented as they are implemented and tested.
